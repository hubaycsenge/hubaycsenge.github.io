Robots surveyed as emotional-model prior art

From szabo-2010-emotional-engine's comparison, scored on short/medium/long-term response, probabilistic behaviour and ethological grounding:

Robot Emotion model Notes
Kismet emotions + drives; drives on a slower timescale form "mood"; winner-take-all arbitration theories from infant social development, psychology, ethology, evolution. Joy 82.4%, fear 47.1%
Aibo drives + six basic emotions; stochastic state machine for non-repetition behavioural system inspired by canine behaviour; reflexive vs deliberate
iCat mode animation (medium-term) + action animation (short-term); probabilistic automaton animation principles for believability
Probo arousal–valence space → specific emotion + intensity; 3-level framework (reactive/routine/reflective), first two implemented therapeutic, huggable. Joy 100%, fear 65%
Ifbot facial expressions mapped to a 3D emotional space via a 5-layer perceptron recognises emotion from voice tone
EmotiRob each action/word associated with a vector of primary emotions companion robot, therapeutic

Recognition rates collected in emotion-recognition-benchmarks.

What this table shows

  • Arousal–valence (Probo) vs discrete states (Aibo, Kismet, Szabó) is the live representational split — the same one in emotion-model-comparison.
  • Multiple time layers are near-universal: short-term emotion vs medium-term mood appears in Kismet, iCat, Probo and both Szabó papers. This is settled practice, not an open question, and emotion-engine should adopt it.
  • Ethological grounding is rare — only Aibo, Kismet and the Szabó model claim it. This is where the Hungarian programme is genuinely distinctive.
  • Every one of these is face- or body-articulation-based. None expresses emotion primarily through motion quality and light, which is what robot-platform must do. That gap is an opportunity, and a risk.
