Two papers about tooling around the FRI fuzzy automaton, not about new behaviour models. Their value to this thesis is methodological.

Ethologically Inspired Human-Robot Interaction Interfaces

Presents the interfaces built for the ethological model: simulated environments and real robot hardware with sensors and cameras. The model itself is the FRI fuzzy automaton loaded with rules extracted from an ethological test procedure; the paper's contribution is the communication methods and protocols between components.

A Novel Application of the 3D VirCA Environment (Acta Polytechnica Hungarica)

Embeds the MATLAB fuzzy-automaton model into VirCA, a 3D collaborative augmented-reality arena, via proxy CyberDevices controlled over UDP. Motivation: a human observer can interact with a simulated dog agent in the same way an ethologist observes a real one, so a formal ethological model can be tested against the paradigm that produced it.

Framed within "Cognitive Infocommunications" and the Future Internet / Internet of Things agenda — a 2012 framing that has dated, and is not load-bearing.

Why this matters here

A simulation-first validation path. Before the human study (validation-study) there is an established route in this group: implement the model, drive an agent in a virtual environment, and have humans interact with it. That de-risks the engine before hardware and ethics are in play, and it is cheap.

It also sets up vincze-2021-automatic-coding, which automates the coding of exactly these simulated interactions.

Limitations

  • Engineering/integration papers. No behavioural results, no user study, no performance figures.
  • VirCA is a specific 2010s Hungarian platform; whether it is still maintained or reachable from ROS 2 is unknown and should be checked before relying on it. #needs-source
  • Overlaps substantially with the Kovács series in its model description.
