The most recent paper in the corpus (2021) and the one that shows where this research programme had got to most lately. Directly relevant to validation-study: it attacks the measurement problem, not the model.

The problem

Behavioural coding — categorising observed behaviour into predefined elements — is done by trained human observers, in real time or from video. It is resource-hungry, observers disagree with each other, and even skilled observers make mistakes. Existing computer tools (e.g. BORIS) help with timestamps and data handling but still require the human to decide what behaviour is being shown.

The proposal

Automatically code behaviour elements in a simulated dog–human interaction, using only the spatial position data of the participants — no access to the simulation's internal states. Connected to the existing simulation system (vincze-2012-interfaces-and-virca), evaluated on scenarios where a simulated dog agent performs pre-programmed behaviours.

Preliminary result: the method recognised the expected behaviour elements correctly. The authors are explicit that further evaluation is necessary.

Why the position-only constraint matters

Deliberately blind to inner state, the coder is a genuinely independent observer — it measures what an ethologist would see, not what the model intends. That makes it usable as an evaluation instrument for the thesis' own engine: if the engine drives behaviour and an independent coder recovers the intended behaviour element, that is evidence the expression works, separately from asking humans.

The authors note the obvious extension: applied to real experiments once reliable localisation of live participants is available. robot-platform has exactly that — a lidar plus the DR-SPAAM leg detector produce spatial position data for people in the room. This connection is not made in any source; it is a hypothesis worth testing. Q10 in open-questions.

Limitations

  • Two-page short paper. Preliminary, artificially constructed data, no accuracy figures reported in the text.
  • Simulated agents only; the real-world application is stated as future work.
  • Handles simple behaviour elements; nothing about emotional state.
