Integrate the emotion analysis into the robot's behavioural structure and validate its responses by testing on humans research-proposal.

Was one unsourced sentence. The corpus now supplies a complete methodological template — lakatos-2014-emotion-attribution and gacsi-2016-emotion-attribution are, between them, a protocol this study can adapt rather than invent.

Inherited protocol

Element Precedent
Setting Family Dog Project lab, ELTE; 4.6 × 3.8 m room, 4 wall cameras
Baseline condition wizard-of-oz teleoperation — the natural control against an autonomous engine
Emotion measures open-ended questionnaire first, forced choice second (avoids priming)
Open-ended scoring 4-point scale: formal behaviour description → contextual behaviour → implicit inner state → explicit emotion naming. Cohen's κ = 0.84 with a second coder
Certainty 0–4 self-rated certainty per choice
Attitude NARS (Negative Attitudes towards Robots Scale), pre and post
Behaviour coding Solomon Coder from video
Statistics Shapiro–Wilk → non-parametric (Mann–Whitney, Wilcoxon, binomial); GLMM with binomial/logit for multi-factor; Benjamini–Hochberg correction
Design within-subject, counterbalanced order and stimulus assignment
Ethics ELTE Institute of Biology IRB written approval
Sample 48–81 participants; expect ~30% exclusion for technical faults

Also inherited: an automatic behaviour coder. vincze-2021-automatic-coding codes behaviour elements from spatial position data alone. Combined with the lidar-based person tracking already on robot-platform, this could replace or cross-check human coding — reducing the most expensive part of the protocol and producing an independent measure. Three conditions already exist in code

mecanumbot-behaviours implements a signalling-modality experiment

Discovered in the 2026-07-28 repository re-clip. Csenge's own behaviour package ships three leading-behaviour trees on one navigation substrate:

Condition Signalling channel
Control none — navigation only
Doglike neck / gripper gestures on /cmd_accessory_pos
LED LED patterns via set_led_status

This maps onto the leading behaviour of lakatos-2014-embodiments-demo and isolates which expressive channel carries the leading signal — the open question raised by the platform having no face. Condition is a launch argument; the parameter YAML is selected from the Wi-Fi SSID, and there are two named environment settings files, which is relevant to the "real environment" part of Q3.

But this is not the study below. These are three fixed signalling conditions with no affect model, no arbitration and no learning. They answer "is the dog-like channel more legible than LEDs or nothing", which is valuable and probably a paper — but it is not "does the emotional engine work". Treating one as the other would be the easiest mistake available here.

Also newly available for data capture: mecanumbot_msgs exposes recording scheme services — named per-user lists of topics to record — plus SimBehaviorEvaluation / SimDetectionEvaluation, per-scenario automatic verdicts carrying unsafe-motion, proximity, wrong-target and stale-detection flags. That is scoring infrastructure the protocol below assumed it would have to build. See Q10.

The condition that matters

The prior studies were all wizard-of-oz — the emotional behaviour was performed by a human operator. This thesis builds the thing that was faked. So the decisive comparison is:

autonomous engine vs wizard-of-oz vs no-emotion control

Anything less cannot separate "the engine works" from "dog-derived behaviour is legible", which is already established.

Targets to beat

From emotion-recognition-benchmarks: ~83% recognition for a positive state, ~75% overall across five states. Fear will be the failure mode — expect ~48%, and expect it to be misread as indifference and to provoke negative user reactions.

Still to specify

  • Hypotheses. Presumably that appropriate feedback improves cooperation and acceptance — but see Q8 in open-questions: the corpus contains a citation that robot emotion expression sometimes worsens perception.
  • Cooperation and acceptance measures. NARS covers attitude; a task-performance or cooperation measure is still missing. #needs-source
  • Real environment. The novelty claim (Q3) is undercut by a lab study. The home-care setting of ichikawa-numakunai-2012-roman is the corpus' answer to "which real environment" and is worth considering.
  • Long-term interaction. social-competence as defined by miklosi-2017-ethorobotics emerges over time and cannot be measured in one session. Every study in the corpus is single-session — so none tests the framework's central construct. A longitudinal design would be a real contribution, and is expensive.
  • Ethics approval route and timeline — start early.
